# 版本记录

## v0.7.2（2026-11-19）

### 修复

- **四象限改用上限归一化**：横轴改为“电流 / 电流上限 %”，纵轴改为“温度 / 温度上限 %”，以 **100%** 为分界；只有任一维度超过设定上限才进入异常象限。
- **停机/启动不再误入异常象限**：电流从运行降到 0 时占比趋近 0%，仍落在“双正常”区域，不再因为历史基线偏差过大被标成异常。
- **不再依赖 30 天基线**：四象限查询只需要最新读数，没有基线样本也可展示。

- 四象限状态：双维度均 ≤100% 为正常；单维度 >100% 为警告；双维度 >100% 为严重。

## v0.7.1（2026-11-18）

### 修复

- **电流基准改为额定电流**：分析、负载率和电流对比统一以电机 `rated_current_a` 作为基准，避免长时间关机后历史平均电流过低，导致开机时偏离值和负载显示异常。
- **电流偏离告警下线**：移除 `current_deviation` 通知，电流只在超过设定上限的过载触发线时告警，避免加卸载/启停的正常电流变化误报。
- **温度/电流过载按上限计算**：新增 `overload_pct`（默认 10%），触发线 = 设定上限 × (1 + 过载偏离)。例如最高电流 600 A、过载偏离 10%，660 A 才通知；温度同理，低于上限不处理。
- **三相不平衡复采修复**：不平衡首次命中不会立即推送，而是进入 `alarm_streaks`；每 5 分钟复采，连续 3 次仍不平衡才告警，任意一次正常则取消。
- **复采范围**：复采只读取待确认电机，避免整网点位重复高负载采集。
- 温度/电流确认次数仍可在阈值页设置（默认 3，范围 1–10）。

### 数据库

- 新增 Alembic 迁移 `e7b3f1a6c920_add_overload_pct.py`，为电机增加 `overload_pct`，默认 10。

### 验证

- 后端 pytest：**25 passed**；flake8 0 error。
- 前端 ESLint 0 error/0 warning，`vue-tsc --noEmit` 通过，Vite 构建通过。
- 测试覆盖：额定电流基准、过载 10% 触发线、三相不平衡连续复采、温度仅上限告警。
- **待现场验证**：额定电流整定、过载偏离百分比、5 分钟复采与现场电网波动的匹配。

## v0.7.0（2026-11-18）

### 调整

- **移除均值曲线**：总览趋势只显示单台电机，默认选中第一台，避免不同功率电机的均值造成误导。
- **曲线点位详情**：点击趋势曲线任意位置，按最近时间点打开该电机详情；详情按该时刻回溯 24 小时数据，显示该时刻温度、三相电流、振动、状态和最近告警。
- **24 小时按当天窗口**：24 小时曲线改为所选日期的本地 00:00 开始（今天为 00:00–现在），不再滚动最近 24 小时；页面显示日期与时间段。
- **温度告警只看上限**：移除温度偏离通知；温度低于设定上限不告警，只在超过上限时生成告警，避免启停、加卸载造成误报。
- **异常复采确认**：温度超上限、三相电流不平衡/超上限首次命中后，按 5 分钟间隔复采；默认连续 3 次（含首次）仍异常才生成告警，偶发异常忽略。确认次数可在阈值页调整。
- **窗口与复采配合**：复采读数按 5 分钟时间戳入库，避免覆盖正常采集；`alarm_streaks` 记录确认进度，正常或状态切换会重置。
- **默认确认次数**：温度/电流确认次数默认由 2 调整为 3；新增迁移同步默认值和已有默认值。
- `temp_notify_base_c` 不再参与告警判断，阈值页移除该输入；字段保留用于兼容历史数据。

## v0.6.0（2026-11-17）

### 新增 / 调整

- **移除温升速率阈值**：阈值配置不再展示“温升速率线”，告警引擎移除 `temp_rise` 通知规则；趋势分析中的温升斜率仍保留为分析指标。
- **温度通知下限**：新增 `temp_notify_base_c`（默认 40°C）。温度低于该值时不再发送温度偏离通知，避免工作 40–60°C、待机 20–30°C 的开关机温降造成误报；温度硬上限仍持续生效。

- **确认状态持久化**：新增 `alarm_streaks` 表记录连续命中次数；正常、状态切换或超时间隔会重置计数。
- **采样间隔可配置**：采样间隔保存到 `app_configs.sampling`，前端 1–120 分钟可调；保存后采集线程自动重排下一轮，无需重启后端。
- **运行期配置恢复**：应用启动时从数据库恢复采样间隔，重启后保持。

## v0.5.0（2026-11-16）

### 新增

- **运行状态识别**：按电流自动判定 **工作 / 待机 / 关机**，每台电机可配置关机电流上限、工作电流下限，中间区间为待机。
- **三状态正常值**：工作、待机、关机各自配置电流 / 温度 / 振动正常值，偏离判断优先使用当前状态正常值；状态正常值留 0 时，工作状态回退 30 天基线，待机/关机状态不跨状态比较。
- **状态切换抑制**：状态切换当次不触发偏离、温升、电流不平衡、电流/振动越限通知，温度上限等安全阈值持续生效，避免启停瞬间大波动误报。

- **布局**：趋势图占整行；LoRa 链路独立成行；告警与闭环并排；四象限与重点风险并排，减少空洞区域。
- **历史数据一致性**：基线查询增加上界，避免查看历史日期时误用未来读数；历史链路统计按所选日期 `poll_cycles` 计算。

### 修复

- 真实网关适配 pymodbus 3.8/3.9+ 从站参数：自动识别 `slave`/`device_id`，不再出现 `unexpected keyword argument 'device_id'`。
- 历史模式基线受未来数据污染。
- 演示数据 `poll_cycles` 只覆盖 2 天，历史日期链路统计为 0；扩展为 30 天。

- 采集点新增时切换类型不会自动调整寄存器数量/倍率；增加自动默认值。
