# 版本记录

## v0.4.0（2026-11-13）

### 新增

- **振动速度采集**：温度变送器 `0000H` 为温度，`0001H–0003H` 为 X/Y/Z 三轴速度均方根值，倍率 0.1；总振动幅度按 `sqrt(x² + y² + z²)` 计算，单位 mm/s。
- **振动存储与告警**：`readings` 新增 `vibration_x/y/z/total_mm_s`，`motors` 新增 `vibration_limit_mm_s`（默认 4.5）；新增 `vibration_high` 严重告警，告警描述带三轴数值。
- **振动对比与展示**：总览卡片显示振动总值；趋势图支持“温度 / 电流 / 振动”曲线多选，振动使用第三 Y 轴；同类对比新增振动总值指标；电机详情展示三轴与总值；自身分析新增振动规则。
- **通知机器人独立页面**：新增 `/notifications`，集中维护飞书 App ID / App Secret / Chat ID、启用开关、发送测试、长连接状态与通知策略；设置页只保留阈值和采集参数。
- **飞书应用通知**：告警时服务端生成电机监测快照 PNG，上传飞书取得 `image_key`，发送带“已解决 / 未解决”按钮的富文本卡片；Webhook 作为发送失败时的兼容回退。
- **卡片回调闭环**：使用飞书官方 SDK `lark-oapi` 的 WebSocket 长连接订阅 `card.action.trigger`；点击“已解决”关闭告警并设置 30 分钟抑制，点击“未解决”将告警置为已确认，操作写入审计日志。
- **凭据安全**：App Secret 只保存在本地数据库，接口只返回 `secret_set`；长连接状态、最近回调、最近错误在通知页可见。

### 修复

- 修复 lark-oapi 在 API 进程内复用 uvicorn 事件循环导致长连接报 `This event loop is already running`；长连接线程改为独立事件循环。
- 修复总览电机卡片、同类对比缺少振动字段导致前端显示 `—` 的问题。
- 修复三层 Y 轴标签重叠：第二、第三轴显式右置并设置偏移。
- 飞书应用发送失败时自动尝试 Webhook 回退，通知日志记录最终结果。

### 数据库

- 新增 Alembic 迁移 `790d0fedfa18_add_vibration_measurements_and_threshold.py`：`motors.vibration_limit_mm_s`、`readings.vibration_*`。
- 运行期配置新增 `feishu_app`（App ID / Secret / Chat ID / 启用状态），由 `init_db` 自动初始化。

### 验证

- 后端 pytest：**18 passed**；flake8 0 error。
- 前端 ESLint 0 error/0 warning，`vue-tsc --noEmit` 通过，Vite 构建通过。
- 浏览器验证：通知机器人页桌面/390px 移动端、阈值页双列布局、总览三曲线开关与三层 Y 轴、同类对比振动指标。
- 飞书长连接实测：无效 App ID 返回 `1000040346: app_id is invalid`，确认不再阻塞事件循环；真实凭据待现场注入后复测。
- **待现场确认**：真实振动寄存器值与倍率、飞书应用权限/长连接开关、卡片按钮回调。

## v0.3.0（2026-11-12）

### 新增

- **三相电流逐相检测**：电流点按 0000H–0002H 三个保持寄存器分别采集 A/B/C 三相，每相独立判断是否超过单相电流上限。
- **三相不平衡检测**：新增 `phase_imbalance_pct` 阈值（默认 10%），不平衡度 = (最大相 − 最小相) / 三相平均 × 100%；超过 2 倍阈值升级为严重告警。
- **三相展示**：电机详情展示 A/B/C 三相电流与实时不平衡度；阈值配置、设备配置均可设置三相不平衡阈值。
- **告警规则**：新增 `current_imbalance`，`current_high` 改为按三相最大值判断，告警描述包含 A/B/C 三相数值。
- **整页填充布局**：对比分析四个模式（自身/同类/四象限/趋势）与阈值通知页自适应填满可视区域；同类对比增加组内摘要与评分口径，趋势/四象限图表动态占满高度。

### 优化

- 单相电流上限沿用原 `current_limit_a` 字段，界面文案改为“单相电流上限”，避免与三相平均值混淆。
- 设置页新增“三相不平衡”阈值输入；设备配置电机表单同步增加。
- 告警/设备规则文档与 API 文档同步 `phase_imbalance_pct` / `current_imbalance`。

### 数据库

- 新增 Alembic 迁移 `921948d56e2c_add_phase_imbalance_threshold.py`，为 `motors` 增加 `phase_imbalance_pct`，默认 10。

### 验证

- 后端 pytest：**12 passed**；flake8 0 error。
- 前端 ESLint/类型检查/Vite 构建通过。
- 浏览器验证：分析页四个模式整页填充、设置页整页填充、电机详情三相显示、三相不平衡配置字段。

## v0.2.0（2026-11-12）

### 新增

- **总览日期回看**：总览页新增主题化日期选择器，可选择今天或历史日期；支持历史 KPI、电机快照、趋势、LoRa 链路统计、当日告警、闭环记录和四象限。
- **历史分析联动**：总览选中历史日期后，点击电机详情 / 对比分析会携带 `date`，自身对比、同类对比、四象限、趋势和电机详情均按所选日期计算。
- **设备配置页面**：新增“设备配置”导航，可在前端维护电机、LoRa 网关和采集点（从站、寄存器、倍率、单位、供电、启停），保存后下一采集周期生效。
- **设备配置 API**：新增电机 upsert、网关 upsert/删除、采集点 upsert/删除接口，写入审计。
- **图表内容增强**：总览趋势图新增末值/最高/最低/平均摘要；LoRa 状态独立整行；新增“重点关注”卡片；历史模式与实时模式使用不同标签。
- **日期 API**：总览、趋势、四象限、自身/同类/趋势分析、电机详情/序列均支持 `date=YYYY-MM-DD`。

### 优化

- **滚动性能**：
  - 移除 8 处 `backdrop-filter`（侧边栏/顶栏/图表提示/遮罩/Toast/批量栏/保存栏等），改为实色分层。
  - 移除 2 个无限动画的 90px 模糊光斑、噪点覆盖层和 5 个 KPI `blur(42px)` 滤镜。
  - ECharts 开启 `useDirtyRect`，入场动画由 450ms 缩短到 280ms。
  - 总览不再每 60 秒强制重绘趋势/四象限，只在采集周期时间戳变化时刷新；减少约 10 次/5 分钟的无效图表请求与重绘。
- **布局**：趋势图占整行；LoRa 链路独立成行；告警与闭环并排；四象限与重点风险并排，减少空洞区域。
- **历史数据一致性**：基线查询增加上界，避免查看历史日期时误用未来读数；历史链路统计按所选日期 `poll_cycles` 计算。

### 修复

- 真实网关适配 pymodbus 3.8/3.9+ 从站参数：自动识别 `slave`/`device_id`，不再出现 `unexpected keyword argument 'device_id'`。
- 历史模式基线受未来数据污染。
- 演示数据 `poll_cycles` 只覆盖 2 天，历史日期链路统计为 0；扩展为 30 天。
- 设备配置编辑电机时可能覆盖原有偏离/温升阈值；改为从设置接口读取原阈值。
- 采集点新增时切换类型不会自动调整寄存器数量/倍率；增加自动默认值。

### 验证

- 后端 pytest：**10 passed**；flake8 0 error。
- 前端：ESLint 0 error/0 warning，`vue-tsc --noEmit` 通过，Vite 构建通过。
- 浏览器验证：总览实时/历史日期切换、日期选择器、设备配置新增网关、历史分析、移动端。
- Docker：`docker compose config` 通过；实际构建仍需在 Ubuntu 部署机执行。
