## 1. 验收范围

本次验收覆盖试点版：

- 现场温度/三相电流/振动速度经 LoRa 网关采集（真实 Modbus 在厂区网验证）。
- 15 分钟采集周期、多网关模型、≤100 点容量。
- 监测总览（含日期回看）、对比分析、告警中心、设备与链路、设备配置、通知机器人、阈值配置 7 个视图。
- 阈值/基线/温升/振动/通信异常告警、飞书应用卡片与长连接闭环、Webhook 回退、审计。
- Docker Compose 部署、数据库迁移、点表导入、数据保留。
- 权限边界：只监测、只报警，不控制电机。
- **v0.2.0 新增**：总览日期回看、历史分析联动、前端设备/点位配置、滚动性能优化与图表内容增强。
- **v0.3.0 新增**：A/B/C 三相逐相越限与三相不平衡判定；对比分析/阈值通知整页填充。
- **v0.4.0 新增**：X/Y/Z 三轴振动采集与总振动合成；通知机器人独立页；飞书应用快照/卡片/长连接回调闭环；总览曲线多选与第三 Y 轴。
- **v0.4.1 修复**：采集点类型补齐振动速度；阈值页改为上下结构，单台电机时不再出现左侧大块空白。

**不在本次范围**：高频振动波形/频谱分析、自动停机、工单系统、移动 App、集团多厂汇总。

## 2. 验收环境与前置条件

| 项 | 要求 |
| :--- | :--- |
| 服务器 | 厂区内网，2 vCPU / 2 GB 内存 / 10 GB 可用磁盘 |
| 软件 | Docker 24+、Docker Compose v2 |
| 网络 | 服务器可访问网关 TCP 端口与飞书开放平台（长连接/图片/消息） |
| 数据库 | PostgreSQL 16 容器，`pgdata` 卷 |
| 网关 | 至少 1 台，确认 IP、端口、RTU/TCP、从站地址 |
| 传感器 | 温度/电流/振动已接线并市电供电，量程/倍率已知 |
| 飞书 | 已创建企业自建应用与机器人，开启长连接、卡片回调，确定通知群与责任人 |
| SSO | 如启用，提供 oauth2-proxy/OIDC 参数与用户头 |
| 浏览器 | Chrome/Edge 最新版；分辨率 ≥1280×720；移动端可选 |
| 测试数据 | 生产验收使用真实点表；演示可用 `MP_COLLECTOR_MODE=simulator` |

## 4. 详细测试用例

### TC-01 系统健康检查

- **步骤**：`curl http://<host>:8000/api/v1/health`
- **期望**：`200 {"status":"ok","service":"motor-monitor-api","version":"0.4.0",...}`
- **实测**：通过（本地 200，响应约 2 ms）。

### TC-02 监测总览

- **步骤**：打开 `/overview`。
- **期望**：5 个 KPI；温度/电流趋势；链路 1/1 网关、12/12 采集点；活跃告警；6 台电机卡片；四象限；闭环统计。
- **实测**：通过。演示数据：在线 6/6，活跃告警 3（M-03 温度越限、M-03 温升、M-05 电流偏离），平均温度 66.8 ℃，平均负载 72.5%，链路完好率 100%。

### TC-03 电机详情

- **步骤**：点击总览 M-03 卡片。
- **期望**：抽屉展示 87.7 ℃ / 上限 85 ℃、196 A / 上限 305 A、负载率 67.6%、偏离 +19.0%；24h 趋势；采集点 T-03/C-03；最近心跳。
- **实测**：通过。

### TC-04 自身历史对比

- **步骤**：`/analysis` → 自身历史对比 → 选择 M-03。
- **期望**：30 天基线 73.5 ℃；当前偏离 +19.3%；温度上限 85 ℃；温升 +1.94 ℃/天；三条规则命中；判定“温度高 / 电流正常”；建议检查风道/轴承/润滑。
- **实测**：通过。

### TC-05 同类电机对比

- **步骤**：同类电机对比 → 泵组A / 空压站 / 风机组切换。
- **期望**：4 项指标条形图；综合排名；组内洞察。
- **实测**：通过。泵组A：M-01 得分 5.0、M-06 4.9、M-02 3.5，洞察“组内指标接近”。

### TC-06 温度 × 电流四象限

- **步骤**：温度 × 电流关联。
- **期望**：6 个点；M-03 位于温度高/电流正常；M-05 位于温度正常/电流异常；点击点可查看详情。
- **实测**：通过。M-03 +19.2%/+4.3%，M-05 +4.6%/+18.1%。

### TC-07 趋势分析

- **步骤**：趋势分析 → M-03 → 24h/7d/30d。
- **期望**：双轴趋势、温度上限、事件标记、最高/最低/平均/斜率、结论标签。
- **实测**：通过（7 天：最高 87.7 ℃、最低 70.95 ℃、平均 80.03 ℃、+1.926 ℃/天，标签“持续恶化”）。

### TC-08 告警列表与筛选
