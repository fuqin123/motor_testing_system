## 2. 需求决策

| 项 | 决策 |
| :--- | :--- |
| 采集周期 | 15 分钟，按 15 分钟边界对齐 |
| 传感器供电 | 市电供电；不实现电池电量展示 |
| LoRa 参数 | 记录 470 MHz / 1200 bps；**“1200”的单位待现场确认**，可配置 |
| 网关 | 当前 1 个，模型支持多网关顺序采集 |
| 点位 | ≤100，当前演示 6 台电机 × 2 个传感器 |
| 并发 | ≤10 在线用户；单 API worker + 内置采集线程 |
| 部署 | Docker Compose（Postgres + FastAPI + Nginx/Vue） |
| 认证 | 试点 `off`；生产预留 SSO 代理模式 |
| 分析 | 规则可解释：自身基线、同类、四象限、趋势；不做黑盒模型 |
| 告警 | 只监测/只报警；不写寄存器、不控制 |

## 3. 交付内容

### 3.1 后端

- 10 张表：`gateways`、`motors`、`sensors`、`readings`、`alarms`、`notification_logs`、`poll_cycles`、`app_configs`、`audit_logs`（另有 `alembic_version`）。
- 采集：pymodbus RTU over TCP / Modbus TCP，15 分钟线程调度，多网关顺序读取，单点重试，手动召测。
- 告警：7 类规则、30 天基线、7 天温升斜率、活跃去重、人工闭环 30 分钟抑制、警告自动闭环、飞书通知重试。
- 分析：15m/1h/6h 分桶、自身/同类/象限/趋势、全部电机均值趋势。
- API：健康、系统、总览、电机、分析、告警、设备、设置共 20+ 路由；自动 OpenAPI。
- 运维 CLI：`init-db`、`import-points`、`seed-demo`、`collect-once`、`check-config`。
- 迁移：Alembic 初始结构 + 告警抑制窗口两个版本。
- 测试：8 个 pytest 用例。

### 3.2 前端

- Vue 3 + TypeScript + Vite + Pinia + Vue Router + ECharts。
- 5 个视图：监测总览、对比分析、告警中心、设备与链路、阈值与通知。
- 复用原 `motor-monitor-ui` 的暗色工业设计系统；移动端侧边栏、卡片单列、表格横向滚动。
- 真实 API 接入，替换原静态模拟数据；60 秒总览刷新、30 秒告警刷新。
- 图表：双轴趋势、基线带、阈值线、事件标注、四象限、迷你 Sparkline、仪表弧。
- 交互：电机详情抽屉、告警详情/闭环、设备详情/召测、阈值滑杆、责任人维护、飞书测试、报告 Markdown 生成/下载/复制。
- 构建：`vue-tsc --noEmit && vite build` 通过；ESLint 0 error / 0 warning；Prettier 格式化；路由懒加载，主入口约 126 KB，ECharts 独立 chunk 约 1.1 MB。

### 3.3 部署与文档

- `docker-compose.yml`：Postgres 16 + FastAPI + Nginx/Vue，健康检查、数据卷、配置只读挂载。
- Alembic 自动迁移入口；`.env.example`；点表示例。
- 文档：技术栈、整体框架、开发记录、验收、API、部署手册、README。

## 4. 开发过程

- 阅读 `docs/项目规范.md`、`docs/大电机风险检测系统.md`。

## 5. 问题与修复

| # | 现象 | 根因 | 修复 | 验证 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | SQLite 建表报 `index ix_readings_ts already exists` | `ts` 列 `index=True` 与显式 `Index("ix_readings_ts")` 重复 | 去掉列级重复索引 | `seed-demo` 成功 |
| 2 | 模拟采集后突然出现 7 条新告警 | 模拟器以固定公式生成，与演示基线偏离大，覆盖了原有读数 | 模拟器以最新读数为锚点做小幅波动；M-03/M-05 保留异常趋势 | `collect-once` 仅新增 1 条温升告警（后续可改为种子数据内置） |
| 3 | 对比分析页 ECharts 警告 `Can't get DOM width or height` | 4 个面板用 `v-show` 隐藏，隐藏图表以 0 宽高初始化 | 改为 `v-if`，并给 ECharts 初始化兜底尺寸 600×height | 控制台 0 errors；隐藏面板不再初始化 |
| 4 | 前端 TS 构建报 `Timeout`/`number`、ECharts formatter 类型 | `@types/node` 与 DOM 定时器类型冲突；ECharts 回调类型过窄 | 定时器统一 `number`；formatter 使用 `any` 适配 ECharts 联合类型 | `npm run build` 通过 |
| 5 | 人工闭环后同一告警下一周期立即重建 | 规则条件仍满足，缺少闭环冷却 | 新增 `alarms.suppressed_until` + 30 分钟抑制 + Alembic 迁移 + 回归测试 | pytest 8 passed |
| 6 | 同类对比电机名称被截断、排名条过短 | 固定 92px 名称列；分数 ×4 缩放不合理 | 名称列只显示编码并加 title；排名条按最大分数归一化 | 浏览器检查 |
| 7 | 四象限 X 轴名称被卡片裁切 | ECharts value 轴 name 位于末端，超出绘制区 | 移除轴内 name，图表下方增加“纵轴/横轴”说明 | 浏览器检查 |
| 8 | 分析图表顶部出现被裁切的 `°C/A` 字符 | 轴 name 超出 grid 顶部 | 移除轴 name，保留图例说明 | 浏览器检查 |
| 9 | 原始 UI 的 30 秒文案与最终 15 分钟不一致 | 静态设计参考未同步 | 生产前端统一使用 15 分钟；README 说明参考目录非生产代码 | 页面文案检查 |
